# v0.9.1 — Demo Preview refinements

This **Pre-release** refines Me and Skills before the formal demo.

## Changes

- Me retains Fitness and SaaS companies and adds ENTP, Travel, Apex Legends, Anime and Nature, with matching outline icons and muted colours.
- A shared, code-owned personal note describes Hongxiang's interest in candid exchanges of ideas and whole evenings talking with friends in the living room. Restored cards use the current approved note and tags.
- The Agent and Me follow-ups receive the same public personality and interests. No favourite anime, destinations or unshared routines are inferred; MBTI remains self-description.
- Skills uses only two tag surfaces: deep blue for the existing highlighted skills and light blue for every other skill, including Soft Skills.
- Removed “Python & Java backend. AI workflows. Full-stack delivery.” from the Skills header.
- Updated the README, learning handbook and package/lockfile version to 0.9.1. The v0.9.0 release and offline handbook attachments remain available as their original snapshot.
