# v0.9.0 — Demo Preview

v0.9 is the milestone before the formal demo: the current portfolio experience, the completed photo collection and a source-based learning handbook, published together as a GitHub **Pre-release**.

## What is included

- Refined desktop/mobile chat visuals, six output presentations and five quick-question entry points.
- Grounded read-only tool workflow, contextual suggestions, the curated 40-entry question snapshot, preset reuse and tab-local conversation recovery.
- Single-photo Fun Facts cover, an ordered 29-photo fan, full-frame viewing and on-demand Big Three training-video tabs.
- Glass-star suggestion control with the reference-frame liquid cycle, keyboard/reduced-motion support and media cleanup.
- Rewritten GitHub README with product screenshots, architecture overview, local setup, verification and explicit scope limits.
- A Chinese handbook covering system boundaries, message/tool sequences, API and data contracts, UI state, caching, cancellation, media, operations and prioritized learning/improvement work.

This release preserves runtime behavior apart from package-version metadata. A photo regression now waits for focus restoration before sending arrow keys, avoiding a test scheduling race without changing the application. Its source includes the already deployed gallery changes that were not part of the earlier v0.2.4 GitHub release.

## Release scope and limits

- **Source release:** package `0.9.0`, Tag `v0.9.0`, GitHub Pre-release.
- **Production:** this release does not redeploy the server. The last verified production source remains `018a0d3`, deployed on 2026-10-29; see [its acceptance record](../deployment-2026-10-29.md).
- **Preview status:** no Portfolio accounts, database-backed history, live vector retrieval, arbitrary/background tools or model-token streaming are claimed. Footprints and some case studies remain upcoming.
- **Next engineering work:** explicit upstream cancellation, server-side cost/usage control, stronger output boundaries, observability and versioned real-model evaluation. These are proposals, not completed features.
